# 『ふたりのリズム』の執筆入口

[共通手順](../../../docs/WRITING.md)に従い、作品rootの `work.json` から対象ID・本文パス・前後場面・設定を確認する。旧manifestや旧repoのCLIは使わない。

| 依頼 | テンプレート |
| --- | --- |
| 場面の目的・転換を整理 | [設計](templates/plan.md) |
| 指定場面を改稿 | [改稿](templates/revise.md) |
| 問題点と修正案を確認 | [レビュー](templates/review.md) |

特に人物の既知情報、呼称、時系列、関係の距離、歌・競技の動作と結果を確認する。対象と必要な前後・設定だけを読み、本文全体を再生成しない。

構造を変える依頼では `work.json` と宣言パスを整合させ、固定IDを再採番しない。提案と確定を分け、依頼範囲の変更だけを反映する。アーカイブは編集しない。
