# 『まっしゅ凄腕へのいばら道』の執筆入口

[共通手順](../../../docs/WRITING.md)に従い、作品rootの `work.json` から対象の章・話IDと本文パスを確認する。

| 依頼 | テンプレート |
| --- | --- |
| 目的・参照範囲・受入条件を整理 | [計画](templates/plan.md) |
| 指定本文や資料を更新 | [改稿](templates/revise.md) |
| 内容・構造・根拠を確認 | [レビュー](templates/review.md) |

投資・技術の事実は時点と根拠を確認し、確認済みの事実、主人公の当時の判断、推測・提案を分ける。未指定の数値・判断を追加しない。台帳・索引への波及は理由と対象を示し、提案を自動的に確定設定へ保存しない。
