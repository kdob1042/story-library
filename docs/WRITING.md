# 執筆・改稿の共通手順

チャットで作品・対象の話や場面・変更目的を受け取る。IDが不明なら `library.json` と対象の `work.json` から解決し、表示番号やファイル名から推測しない。

1. 対象本文と必要な前後場面を読む。[設定の分担](WORKFLOW.md#設定文書の分担)から必要な資料を選ぶ。パスは作品root基準。
2. 対象の目的、開始時点、転換点、終わりの変化を確認する。既知情報・呼称・時系列・関係の距離を前後と照合する。
3. 指定範囲を改稿する。固定ID・見出し・読書順を保持し、未指定の設定・出来事・事実・判断を確定事項として追加しない。
4. 人物、因果、構成、文体、連続性を確認する。説明の重複、過剰な反応、同じ型の会話を削る。
5. 変更理由と完成本文または差分を示す。設定・索引などへの波及が必要なら、理由と対象ファイルを分けて示す。

前後場面は整合確認用。無関係な本文・設定・アーカイブは編集しない。設定変更が依頼範囲に含まれる場合は担当文書へ反映し、同じ内容を複写しない。既に受けた保存指示の範囲でPRへ反映する。

設計だけなら目的と変更案、レビューだけなら重要度順の指摘・根拠・修正案を返す。作品別の `ai/` は固有の確認観点と依頼例だけを持つ。漫画化による新しい行動・台詞・因果の提案は[Manga Director](../skills/manga-director/SKILL.md)で扱う。
